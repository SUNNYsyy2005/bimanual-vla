1. 数据集归一化

只统计数据集训练 split 的 state/actions；不读取模型权重数值。模型系列仅用于匹配动作序列与数据合同。

Norm batch size 只影响统计计算吞吐和显存/内存占用，不需要与训练 batch size 一致。

2. 提交模型微调

根据数据集匹配场景、机械臂型号、单双臂和动作输出；允许使用符合相同配置的其他数据集权重。

基础模型单独列出；checkpoint 同时匹配场景、机械臂型号、单双臂和动作输出类型。

视觉编码器冻结。训练期 RTC 随机保留动作前缀，仅优化后缀；8 steps 在 20 Hz 下覆盖 400 ms。继续训练会沿用 checkpoint 的参数范围和 RTC 配置。

0=只保留最新；2000=保护 2k 倍数 checkpoint。

Episode 划分：自动加载已保存的 norm 划分。Keep period 控制 Orbax 额外保留哪些 step；若要每 2k 保留一次，请同时设置 Save interval=2000、Keep period=2000。

Action expert 全量微调需要为梯度和优化器状态预留显存；全局 batch 与 FSDP 按实际资源设置。自动评测使用 held-out episodes；没有空闲卡时记录 skipped。

Checkpoint 存储目录为单一写入位置；“允许扫描 / 读取的 checkpoint 目录”支持多个只读来源，存储目录会自动包含在其中。
