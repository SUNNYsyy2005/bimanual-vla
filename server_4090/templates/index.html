上传数据集

后端提供并行分块、SHA256 和断点续传接口。目录数据集请在采集机执行：

python upload_dataset_4090.py DATASET_DIR --name my_dataset --server http://192.168.101.9:8090 --token TOKEN --workers 4 --merge

--merge 会把上传目录中的全部 episodes 追加到同名兼容数据集；同名数据集不存在时按首次安装处理。--overwrite 与 --merge 互斥。

服务端安装前检查 tar 路径安全、LeRobot v2.1 结构、视频帧数，并用实际 LeRobot loader 读取首尾样本。
