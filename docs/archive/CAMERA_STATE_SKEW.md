# Camera/State Skew警告说明

## 警告信息
```
WARNING Inference snapshot skipped: nearest camera/state skew 77.2ms exceeds 75.0ms
```

## 这是什么？

**Camera/State Skew (偏差)**: 摄像头帧时间戳 和 机械臂状态时间戳 之间的时间差

### 为什么需要检查skew？

推理需要同步的观测数据：
```
观测 = {
    图像: cam_high, cam_left_wrist, cam_right_wrist
    状态: 关节角度, 夹爪位置
    指令: "pick up the object"
}
```

如果图像和状态的时间戳相差太大：
- 图像显示机械臂在位置A
- 状态说机械臂在位置B
- 模型会产生错误的推理

## 阈值设置

**默认阈值**: **75ms**（0.075秒）
```python
DEFAULT_MAX_IMAGE_STATE_SKEW_S = 0.075
```

**可通过参数调整**:
```bash
--max-image-state-skew-ms 100  # 放宽到100ms
```

## 77.2ms超过75ms正常吗？

### ✅ 偶尔出现（<5%）：正常
- 系统负载波动
- GC暂停
- 网络抖动
- 不影响整体性能

### ⚠️ 频繁出现（5-20%）：需要注意
- 说明系统接近极限
- 可能影响推理质量
- 建议优化或降低频率

### ❌ 持续出现（>20%）：有问题
- 摄像头帧率不稳定
- 机械臂反馈延迟
- CPU/网络过载
- 需要排查根因

## 为什么会出现skew？

### 1. 摄像头延迟
```
摄像头捕获: 33ms (30fps)
编码/传输: 10-20ms
读取延迟: 5-10ms
──────────────────
总计: 48-63ms
```

### 2. 机械臂反馈延迟
```
CAN反馈: 5ms (200Hz)
SDK处理: 1-2ms
网络: minimal (本地)
──────────────────
总计: 6-7ms
```

### 3. 时间差累积
如果摄像头刚好在机械臂反馈之后才到达：
```
t=0: 机械臂反馈到达
t=50: 摄像头帧到达
skew = 50ms ✓ OK

但如果:
t=0: 机械臂反馈到达
t=77: 摄像头帧到达
skew = 77ms ✗ 超过75ms
```

## 影响

### 当skew超过阈值时:
1. **跳过这次推理** - 不发送给模型
2. **等待下一个观测** - 寻找skew更小的
3. **推理频率降低** - 如果频繁跳过

### 示例场景
```
目标: 5Hz推理 (每200ms一次)

理想情况:
t=0:    推理 #1
t=200:  推理 #2
t=400:  推理 #3
实际: 5Hz ✓

有skew时:
t=0:    推理 #1
t=200:  跳过 (skew 77ms)
t=400:  推理 #2
t=600:  跳过 (skew 80ms)
t=800:  推理 #3
实际: 3Hz ✗ 降低了
```

## 如何判断是否正常？

### 统计方法
运行一段时间，统计警告频率：

```bash
# 查看日志中的skew警告
grep "skew.*exceeds" inference.log | wc -l

# 假设运行了10分钟，5Hz推理
# 理论推理次数 = 10 * 60 * 5 = 3000次
# skew警告次数 = 150次
# 比例 = 150 / 3000 = 5% ✓ 可接受
```

### 判断标准
- **<5%**: ✅ 正常，系统健康
- **5-10%**: ⚠️ 可接受，但接近边界
- **10-20%**: ⚠️ 需要优化
- **>20%**: ❌ 严重问题，影响性能

## 优化方法

### 1. 放宽阈值（最简单）
```bash
--max-image-state-skew-ms 100
```

**优点**: 立即生效，减少跳过
**缺点**: 允许更大的时间不同步

**建议**: 如果skew在75-90ms之间，可以放宽到100ms

### 2. 降低推理频率
```
5Hz → 4Hz
推理周期: 200ms → 250ms
更多时间等待同步的观测
```

### 3. 优化摄像头
- 使用更快的摄像头
- 降低分辨率（256×256 → 224×224）
- 优化摄像头驱动
- 使用硬件JPEG编码

### 4. 优化系统负载
- 关闭不必要的程序
- 提高进程优先级
- 使用实时内核

### 5. 检查网络
```bash
# 如果摄像头是网络摄像头
ping <camera-ip>
# 延迟应该<1ms
```
