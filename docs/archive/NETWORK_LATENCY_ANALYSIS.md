## 优化建议

### 1. 减少协议开销（潜在节省 20-30ms）

#### a) 减少WebSocket帧数
- 将数据打包成单个大帧，而不是多个小帧
- 配置WebSocket max_frame_size

#### b) 启用TCP_NODELAY
- 禁用Nagle算法，减少延迟
```python
socket.setsockopt(socket.IPPROTO_TCP, socket.TCP_NODELAY, 1)
```

#### c) 调整TCP窗口大小
- 增加TCP发送/接收缓冲区

### 2. 减少图像数据大小（潜在节省 30-40ms）

#### a) 降低分辨率
- 256×256 → 224×224: 减少23%数据
- 256×256 → 192×192: 减少44%数据

#### b) JPEG压缩传输
- 压缩比可达 10:1
- 576KB → 60KB
- 上传时间: 70ms → 10-15ms
- **节省约 55ms！**

### 3. 优化序列化（边际收益）
- 序列化已经很快 (0.17ms)
- 不是主要瓶颈

### 4. 使用更快的网络连接
- 确认是否真的是千兆网
- 检查网线质量
- 更换更好的网卡
